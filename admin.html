Administración del catálogo

Importa un Excel para agregar productos nuevos y actualizar los existentes por UPC. Los productos que no aparezcan en el archivo no se eliminan.

No subas el Excel a GitHub. La importación se envía directamente a la base central. Usa solo la publishable key en esta página; nunca una secret/service_role key.

Iniciar sesión de administrador

Ingresa con la cuenta de administrador creada en Supabase.

Importar / actualizar productos

Encabezados requeridos: UPC, DESCRIPCIÓN, COSTO, DEPARTAMENTO. Recomendado: guardar UPC como texto para preservar ceros iniciales.

Selecciona un archivo para comenzar.

Cómo funciona la actualización

  • El UPC identifica cada producto.
  • Si el UPC ya existe, se actualizan descripción, costo y departamento.
  • Si el UPC es nuevo, se agrega.
  • Los productos ausentes del Excel permanecen intactos.
  • Se rechaza el archivo si tiene UPC duplicados o datos obligatorios inválidos.
